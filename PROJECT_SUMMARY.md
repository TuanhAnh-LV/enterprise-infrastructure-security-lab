# Project Summary

## Enterprise Infrastructure & Security Operations Lab

This project demonstrates the design and operation of a small enterprise environment with security controls and centralized visibility built in from the start.

### Business scenario

An organization needs resilient internal connectivity, controlled access between trust zones, securely published services, centralized Windows administration, and a monitoring workflow that supports first-line incident investigation.

### Delivered solution

- Segmented the environment into Management, Server, Office, Voice, Guest, IT, DMZ, SOC, and Transit networks.
- Added network resilience with dual core switches, HSRP, LACP, Rapid-PVST, OSPF, and FortiGate Active-Passive HA.
- Applied firewall policy, NAT/VIP, remote-access VPN, SSL inspection, Web/DNS filtering, antivirus, IPS, and application control.
- Deployed AD DS, DNS, DHCP, File Server, Group Policy hardening, advanced audit policy, and PowerShell logging.
- Centralized endpoint and network telemetry in Wazuh using Wazuh Agent, Sysmon, Windows Event Logs, Syslog, FIM, SCA, Syscollector, and Suricata.
- Documented validation evidence and an analyst-oriented incident-triage process.

### Outcome

The completed lab provides an end-to-end view of how enterprise infrastructure, preventive controls, telemetry collection, and SOC analysis work together. It demonstrates hands-on ability across networking, systems administration, security engineering, monitoring, troubleshooting, and documentation.
